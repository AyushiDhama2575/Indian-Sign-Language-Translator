# Indian Sign Language (ISL) Translator

An innovative AI-powered Indian Sign Language (ISL) Translator designed for assistive technology and accessibility. It features a two-way translation system supporting 22 Indian languages, converting text, voice, and real-time webcam hand gestures into sign language videos and synthesized speech.

## Key Features
1. **Text & Voice to ISL Translation:** Supports text input across 22 Indian languages and voice-to-text input, translating them into sign language videos.
2. **Live Webcam Detection:** Utilizes real-time computer vision to detect hand gestures, predicting sign language symbols and converting them into text and speech.
3. **Smart Sentences:** Generates meaningful sentences from detected sign sequences using AI.
